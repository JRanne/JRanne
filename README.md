## Vimma

[**Vimma**](https://github.com/vimma-browser/vimma) is a keyboard-first web browser built on
Firefox, and my hands-on test bed for AI-driven development.

- **Modal like Neovim:** normal, insert, visual and hint modes, plus a tmux-style prefix key
  (`ctrl+b`) for tabs, splits, workspaces and the side panel.
- **Workspaces as containers:** each workspace keeps its own cookies and logins.
- **Local AI agents, kept on a leash:** coding agents such as Claude Code reach Vimma through MCP,
  only inside their own workspace, and every request asks you first.
- **Linux and macOS:** packages for Arch, Debian, Fedora, AppImage and Homebrew; from 0.1.11 the
  macOS builds are signed and notarised by Apple.

Vimma is built largely by AI coding agents under human review — specs, test-first changes,
independent security reviews and automated releases — which makes it a working case study for my
research.
